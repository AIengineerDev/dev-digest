# `docs/temp/` — disposable working documents

Everything in this folder is **scheduled for deletion**. It holds research and
scratch notes that were useful while a piece of work was being figured out and
that stop being useful once the work lands.

Nothing here is a source of truth. Do not link to it from `docs/`, `specs/`, or
any `AGENTS.md`: a link into this folder is a link that will break on purpose.
When a fact in here turns out to be durable, move that fact into the surface
that owns it — `docs/` for how the system works, `specs/` for intent,
`INSIGHTS.md` for a decision or a trap — and delete it from here.

Each document states its own delete-when condition at the top. When that
condition is met, delete the file. When the folder is empty, delete the folder.
